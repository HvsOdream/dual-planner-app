# 언어 (한국어 · 영어 · 중국어 간체 · 번체)

0.7.74에서 구조를 넣고, 0.7.75에서 화면 함수의 문구를 감싸고 영어 초안을 채웠다. 화면은 아직 한국어로만 뜬다(`ON = false`).
영어는 `?lang=en`으로 미리 볼 수 있다. 어순이 어긋나는 문장이 남아 있어 아직 켜지 않는다 → `docs/i18n-fragments.md`.

## 어떻게 돌아가나
- **한국어 문구가 원문이자 열쇠**다. 코드에는 한국어를 그대로 두고 `T('문구')`로 감싼다. 사전에 있으면 번역, 없으면 한국어가 그대로 나온다. 그래서 반쯤 옮긴 상태로도 앱이 깨지지 않는다.
- 언어는 `index.html` 머리의 작은 스크립트가 고른다: 주소의 `?lang=` → 메뉴에서 고른 값(`localStorage.dpa_lang`) → (`ON`일 때만) 기기 언어 → 한국어. 기기 언어가 넷 중 어느 것도 아니면 영어.
- 한국어가 아니면 `lang/<언어>.js` 한 장을 본문보다 먼저 읽는다. 파일은 `window.DP_DICT = { '한국어': '번역', … }` 하나뿐이다.
- 중국어는 `zh-TW`·`zh-HK`·`zh-MO`·`zh-Hant*` → 번체, 나머지 `zh*` → 간체.

## 쓰는 법
| 경우 | 쓰는 법 | 사전 |
|---|---|---|
| 그냥 문구 | `T('연결됨')` | `'연결됨': 'Connected'` |
| 바뀌는 값 | `T('{n}개 남음', { n })` | `'{n}개 남음': '{n} left'` |
| 영어 복수 | 값 이름을 `n`으로 | `'{n}개': ['{n} item', '{n} items']` |
| 같은 한국어, 다른 자리 | `T('끝', null, 'path')` | `'끝@path': 'Finish'` |
| 목록·상수에 든 문구 | 정의에 `N('가죽')`, 쓰는 곳에 `T(이름)` | `'가죽': 'Leather'` |
| 화면에 박힌 글자 | 태그에 `data-t` (`<span data-t>오늘</span>`) | `'오늘': 'Today'` |
| 박힌 aria-label | 태그에 `data-t-aria` | |
| 요일 | `wdn(date.getDay())` | 코드 안 `WDS` |
| 몇 월 며칠 | `kDate('2026-12-08')` | 코드 안 |

지킬 것:
- `T()` 안에 `${}`를 쓰지 않는다. 문장을 조각내 이어 붙이지 않는다(어순이 언어마다 다르다). 값은 `{이름}`으로 넣고 문장 하나를 통째로 열쇠로 삼는다.
- 태그는 열쇠에 넣지 않는다. 굵게 할 낱말이 문장 가운데 있으면 `T('{a}까지 {b}단계', { a: '<b>…</b>', b })`처럼 값으로 뺀다.
- 사용자가 적은 글(할 일, 메모, 역할 이름)은 옮기지 않는다.

## 점검
```
NODE_PATH=<acorn·acorn-walk 설치 경로> node tools/i18n-wrap.js [--dry] 함수이름 …   # 그 함수 안의 한국어를 T()로 감쌈(반자동)
node tools/i18n.js          # 열쇠 수, 사전마다 빠진 열쇠·남는 열쇠·{값} 짝
node tools/i18n.js --todo   # 아직 T()에 안 들어간 문구를 함수별로 세어 docs/i18n-todo.md 에 적음
node tools/i18n.js --check  # 남는 열쇠·문법 오류가 있으면 실패 (web-check에서 돈다)
```
미리 보기: 웹에서 주소 끝에 `?lang=en`, `?lang=zh-Hans`, `?lang=zh-Hant`. 실행 중 `T_MISS`에 번역이 없던 문구가 모인다.

## 문구 말고 따로 해야 하는 것
| 무엇 | 왜 따로인가 | 어디 |
|---|---|---|
| 날짜 읽기 | "금요일까지", "내일 오후 2시 전에"를 읽는 규칙이 한국어 전용. "by Friday", "周五之前"용 규칙을 언어별로 새로 써야 함 | `parseDue` 주변 |
| 비서 AI 지시문 | 지시문·예시가 한국어 기준. 지금은 적은 글의 언어를 보고 답만 그 언어로 씀. 앱 언어를 서버에 같이 보내고 언어별 예시를 둬야 함 | `worker/src/index.js` |
| 알림 문구 | 앱이 꺼져 있을 때 뜨는 글 | `notifText` |
| 표지의 날짜 | 월·일·요일 조합 | `coverParts` |
| 약관·개인정보처리방침 | 법적 문서 | `legal/` |
| 상점 글·스크린샷 | App Store Connect에서 언어별로 | |
| 중국 본토 출시 | 간체는 AI 서비스 신고 등 요건이 따로 있음 | App Store Connect 안내 |

## 순서
1. (지금) 구조 + 탭·메뉴 첫 화면
2. 화면 단위로 감싸기: 오늘 → 할 일 → 계획 → 메모 → 달력 → 메뉴 안쪽 → 포스트잇 → 알림. `docs/i18n-todo.md`의 숫자가 줄어드는지 본다
3. 영어 사전 채우기, 영어 날짜 읽기, 서버에 언어 전달
4. 영어로 페르소나 검증 한 번 → `ON = true`
5. 번체 → 간체

사전 초안(특히 중국어)은 원어민 확인 전이다.
