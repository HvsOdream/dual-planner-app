# 영어로 켜기 전에 남은 일

0.7.78 기준. 화면 문구는 거의 다 `T()`에 들어갔고 영어 사전은 빠진 것이 없다(815개). 아래가 남았다.

## 1. 영어 문장 다듬기 (사전만 고치면 되는 것)
`lang/en.js`는 초안이다. 영어로 화면을 켜고(`?lang=en`) 읽어 보며 고친다. 눈에 띈 것:
- 알림 문장은 0.7.78에서 문장 하나짜리 열쇠로 합쳤다. 「이번 주 숫자」 포스트잇은 아직 쉼표로 잇는 조각이다(`5 done, 2 partly done, busiest role …`)
- `{n}개`류 개수 표기(`3`만 나옴), `Day 1`(연속 일수), `The path`(가는 길) 같은 이름은 원어민 확인이 필요

## 2. 코드에 남은 한국어 (약 70조각)
| 어디 | 무엇 | 어떻게 |
|---|---|---|
| `qaSeed`·`qaDraw` | QA 연습장(개발용) | 그대로 둔다 |
| `parseDue`·`parseTime`·`relFix` | 한국어 날짜 읽기 규칙 | 그대로 둔다(영어는 `parseDueEn`) |
| `'모름'` (`roleFinder`·`setPerson`) | 관계를 모를 때 저장하는 표시말 | 저장 값이라 그대로. 보여 줄 때는 `noGuess()`로 가린다 |
| `'[일정] '`·`'역할 없음'` (`groupInputs`·`weekFacts`) | 서버 지시문이 알아보는 표시말 | 서버와 같이 바꿔야 함 |
| `josa()` | 은/는·과/와 고르기 | 영어 사전에서는 빈 글자로 둠 |

## 3. 서버
- 지시문은 한국어로 쓰여 있고, 답만 사용자가 적은 글의 언어로 한다(영어·일본어·중국어). 앱 언어(`lang`)는 글이 거의 없을 때만 쓴다
- 서버가 돌려주는 오류 글(`error`)과 캘린더 오류는 한국어·영문 코드가 섞여 있다

## 4. 그 밖
- 약관·개인정보처리방침(`legal/`)은 한국어뿐
- 메뉴에 언어 고르기 칸이 없다(`localStorage.dpa_lang`만 읽음). 켤 때 같이 넣는다
- 영어로 페르소나 검증 한 번 → `ON = true`

## 지나간 사고 (다시 안 나게)
0.7.75에서 `tools/i18n-wrap.js`가 태그 없는 문장을 통째로 바꾸면서, 문장으로 잡지 않은 앞뒤 글자(` · `, `B `, `「`)를 버렸다. 한국어 화면 9곳에서 글자가 빠진 채 두 번 나갔다(0.7.75·0.7.76).
- 도구: 앞뒤에 남는 글자가 있으면 통째로 바꾸지 않게 고침
- 확인법: 감싸기 전 버전과 지금 버전을 같은 예시 데이터로 띄워 탭별 글자(aria-label·placeholder 포함)를 대조한다. 차이가 0이어야 올린다
